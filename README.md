## Digital Business Card
this was my first time using html and css and making myself a digital business card for self-promotional purposes.
## process
I created a mockup in figma and created a css Grid. Then added elements (both svg and images) in one by one. I used Transform:translate and overflow:hidden to adjust grid from that point.
## Attribution
The font I used was Karla, designed by Johnny Pinhorn and accessed from google fonts. 
## Accessability
This site uses large, clear letterforms to increase readability as well as short, consice text paired with images with alt text for screen readers.
